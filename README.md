A realistic elliptic billiard simulation with proper physics.

## How to Play
- 🖱️ **Aim**: Click and drag from the white ball
- 🚀 **Shoot**: Release mouse to hit
- 🎯 **Goal**: Sink the ball in the black hole
- 🔄 **Reset**: Refresh the page

## Features
- Real elliptic collision physics
- Velocity-based shooting mechanics
- Green velvet table texture
- Professional ball/hole sizing

## Deployment
1. Clone repo
2. Host on any static server
3. Access via `index.html`
